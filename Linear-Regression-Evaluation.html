1.1 Mean Absolute Error — MAE

The average size of the mistake, ignoring direction.

MAE = average of |Actual − Predicted|

We take the absolute value of every residual (so negatives become positive), then average them. It's easy to explain: "on average, we're off by this much."

Example

Errors of +4, −5, +2 → absolute values 4, 5, 2 → average = 3.67. The model is typically off by about 3.67 units.

1.2 Mean Squared Error — MSE

Squaring the error punishes big mistakes harder.

MSE = average of (Actual − Predicted)²

MSE

Mean Squared Error

Square each residual, then average. Big errors get squared into even bigger numbers — so MSE is sensitive to outliers.

Example

Errors of +4, −5, +2 → squared values 16, 25, 4 → average = 15.0. Notice how the −5 error dominates the score far more than it did for MAE.

1.3 Root Mean Squared Error — RMSE

Undo the squaring to get back to real units.

RMSE = √MSE

RMSE

Root Mean Squared Error

Just the square root of MSE. This brings the number back to the original units — easier to interpret than MSE, while still punishing large errors more than MAE does.

Example

MSE of 15.0 → √15.0 = ≈3.87. So the model is typically off by about 3.87 units — in the same units as the target.

1.5 Which One Should I Use?

Pick the metric that matches what you care about.

Want easy-to-explain?

Use MAE — it's the plain average mistake size.

Want to punish big misses?

Use MSE — large errors count much more.

Want punishment + real units?

Use RMSE — the most commonly reported.

1.6 R² — Goodness of Fit

What fraction of the pattern does the line explain?

R² (R-squared) ranges from 0 to 1. An R² of 0.85 means the line explains 85% of the variation in the data — the rest is noise the model can't capture.
